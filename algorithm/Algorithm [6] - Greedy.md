# Algorithm [6] - Greedy



### 그리디 알고리즘

- 매 선택에서 최적의 상황만을 쫓는 알고리즘
- 항상 최적의 결과를 도출할 수는 없지만 어느정도 근사값을 빠르게 구할 수 있다
- 무조건 큰/작은/긴/짧은 경우대로 극단적 문제 접근
- 주로 정렬 기법과 함께 사용된다

### 그리디 알고리즘 수행 과정
- 해 선택 : 현재 상태에서 가장 최선이라고 생각되는 해를 선택
- 적절성 검사 : 현재 선택한 해가 전체 문제의 제약조건에 벗어나지 않는지 검사
- 해 검사 : 현재까지 선택한 해 집합이 전체 문제를 해결할 수 있는지 검사. 전체 문제를 해결하지 못한다면 다시 '해 선택'으로 돌아가 같은 과정 순환 반복
